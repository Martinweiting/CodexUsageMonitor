# 所有控制項點擊可靠性修正

## 根因與證據

繁體中文活動頁實際點擊額度分頁、右鍵及 Alt+F4 均無反應。測試版訊息佇列紀錄顯示每秒約 25 萬個 WM_MOUSELEAVE（675），左鍵事件未送達處理函式。UpdateHoverStateFromCursor 在游標座標位於可見群組時立即重新 ArmMouseLeaveTracking；被其他視窗遮住時，座標仍在群組內，但游標實際不在此 HWND 上，重新登記立即產生下一個離開訊息，造成輸入飢餓。

另有三個程式可確認的邊界問題：選取中的分頁回傳未處理而落入拖曳；捕捉被其他視窗奪走仍觸發懸浮球點擊；原生選單的巢狀訊息迴圈仍執行 hover 收合。

## 實作與驗收

- 只有游標實際命中本視窗時才能登記離開追蹤，離開回呼不得自行重新登記。被遮住或切換應用程式後訊息量回復正常，下一次點擊可處理。
- 所有分頁命中都消耗點擊，包含已選取分頁；不啟動背景拖曳。
- 滑鼠捕捉中斷與 WM_CANCELMODE 只取消手勢；懸浮球只在有效放開且未拖曳時切換。
- 原生選單開啟期間暫停 hover 幾何切換；關閉後恢復。
- 保留透明度、既有按鍵透明像素命中、繁體字型、背景資料讀取及使用者原始設定。
- Release 原生測試、source contract、diff 檢查；繁體中文實機測試分頁、重新整理、關閉、懸浮球、透明度滑桿、選單與顯示模式。記錄實測範圍及限制，不宣稱已窮舉所有環境。

## 驗證結果

- 修正前佇列記錄：每秒 243912–259554 個 WM_MOUSELEAVE，額度頁左鍵及右鍵沒有送達處理函式。
- 修正後：離開訊息洪水消失，閒置約每秒 23 個計時器訊息；額度點擊收到 513 / 514，full_page 從 1 變 0。
- 繁體 UI 測試版：活動／額度雙向切換、兩頁重新整理、選取中分頁拖曳不移動（x=100、y=100）、透明度滑桿拖出軌道達 80%、設定 X、懸浮球展開、完整→簡單→任務模式、各模式右鍵及模式子選單均通過。
- 新增 WindowInteractionTests 直接驗證隱藏視窗不登記離開追蹤、離開通知與輪詢不重新登記、已選取分頁消耗點擊、WM_CAPTURECHANGED／WM_CANCELMODE 不誤觸發、選單期間不收合。Release CTest 兩組均通過。
- UI 測試使用獨立設定檔，未改動正式版的繁體語言、位置、透明度或開機設定。未窮舉所有 DPI、螢幕組合；未實際切換開機自動啟動。臨時輸入／佇列紀錄已從正式原始碼移除。
